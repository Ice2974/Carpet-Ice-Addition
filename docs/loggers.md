# 记录器列表

## villagerEvents

记录村民真正死亡、成功感染为僵尸村民，以及成功因雷击转化为女巫。默认选项为 `all`。

| 选项 | 内容 |
| --- | --- |
| `all` | 死亡、僵尸化和女巫化。 |
| `death` | 仅真正死亡。 |
| `zombified` | 仅实际转化为僵尸村民。 |
| `witch` | 仅实际因雷击转化为女巫。 |

`/log villagerEvents` 与 `/log villagerEvents all` 等价。消息格式为 `[VillagerEvents] <事件描述> | <维度> | X, Y, Z`。幼年、傻子、无业成年和有职业成年村民会区分显示；命名村民使用 `“名称”（身份）`。

原版三维度显示为主世界、下界、末地。该 Logger 是纯服务端功能，客户端不需要安装 Carpet Ice Addition。死亡消息与村民职业名等原版文本由各订阅玩家的客户端按其自身语言显示；幼年、傻子、无业等标签与消息模板按服务器 Carpet 语言显示，客户端语言与服务器语言不一致时同一条消息可能中英混排。服务器启动不会联网下载原版语言文件，death 输出不依赖网络，也不再有语言资源加载等待或失败暂停。客户端无法翻译的原版键（如其他模组添加的伤害类型或村民职业）会以英文或原始键名兜底显示。
